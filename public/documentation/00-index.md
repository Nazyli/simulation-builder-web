# Dokumentasi Simulation Builder

Selamat datang di panduan penggunaan **Simulation Builder**. Gunakan panduan ini untuk membuat Workflow dengan menyusun dan menghubungkan Node di Studio.

## Mulai dari sini

1. Baca [Pengenalan](01-pengenalan.md).
2. Lihat [Node Catalog](02-node-catalog.md) untuk memilih Node.
3. Ikuti contoh pada [Contoh Workflow](32-contoh-workflow.md).
4. Buka halaman Node yang ingin dikonfigurasi.
5. Gunakan [Port Reference](30-port-reference.md) dan [Configuration Reference](31-configuration-reference.md) sebagai referensi cepat.
6. Jika mengalami masalah, lihat [Troubleshooting](33-troubleshooting.md).
